# Sources

이 데이터셋은 아래 문서의 개념을 참고해 한국어 튜터 Q&A로 재작성한 합성 데이터입니다. 문서 문장을 그대로 복사하지 않고, 학습용 질의응답 형식으로 새로 구성했습니다.

- unity_delta_time: [Unity Scripting API - Time.deltaTime](https://docs.unity3d.com/ScriptReference/Time-deltaTime.html) - Frame interval, frame-rate independent movement, FixedUpdate caveat
- unity_fixed_update: [Unity Scripting API - MonoBehaviour.FixedUpdate](https://docs.unity3d.com/ScriptReference/MonoBehaviour.FixedUpdate.html) - Fixed timestep callback for physics calculations
- unity_rigidbody_addforce: [Unity Scripting API - Rigidbody.AddForce](https://docs.unity3d.com/ScriptReference/Rigidbody.AddForce.html) - Applying force to active non-kinematic Rigidbody and ForceMode behavior
- unity_character_controller_move: [Unity Scripting API - CharacterController.Move](https://docs.unity3d.com/ScriptReference/CharacterController.Move.html) - Absolute movement delta and collision flags; gravity not applied automatically
- unity_prefabs: [Unity Manual - Prefabs](https://docs.unity3d.com/Manual/Prefabs.html) - Reusable GameObject asset template with components and children
- unity_scriptable_object: [Unity Manual - ScriptableObject](https://docs.unity3d.com/Manual/class-ScriptableObject.html) - Data container asset independent from MonoBehaviour instances
- unity_coroutines: [Unity Learn - Coroutines](https://learn.unity.com/tutorial/coroutines) - Operations over time using IEnumerator and yield instructions
- unity_mono_behaviour: [Unity Scripting API - MonoBehaviour](https://docs.unity3d.com/ScriptReference/MonoBehaviour.html) - Base class for Unity C# scripts and event functions
- unity_vector_normalize: [Unity Scripting API - Vector3.Normalize](https://docs.unity3d.com/ScriptReference/Vector3.Normalize.html) - Unit vector with same direction; zero for near-zero vectors
- unity_vector_dot: [Unity Scripting API - Vector3.Dot](https://docs.unity3d.com/ScriptReference/Vector3.Dot.html) - Dot product and direction/angle interpretation
- unity_quaternion: [Unity Scripting API - Quaternion](https://docs.unity3d.com/ScriptReference/Quaternion.html) - Rotation representation, interpolation, gimbal-lock avoidance
- unity_quaternion_look_rotation: [Unity Scripting API - Quaternion.LookRotation](https://docs.unity3d.com/ScriptReference/Quaternion.LookRotation.html) - Create a rotation from forward/up vectors
- ms_csharp_async: [Microsoft Learn - C# async and await](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/operators/await) - Async method suspension without blocking the caller thread
